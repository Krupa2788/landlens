# features/parcels

Feature folder: components, hooks and tests for parcels live together.

- Day 1: `ParcelsList` + a `useParcels` TanStack Query hook (loading / error / empty states)
- Day 2: `AddParcelForm` + `useCreateParcel` mutation (invalidate the list on success)
- Day 3: `SuburbInsights` page with a chart
- Day 4: `ImportParcels` (presigned URL -> direct upload to S3)
